히유 고통 지수 테스트 — Cloudflare 배포본 로컬 미리보기

실행 방법 (Mac)
1. ZIP을 압축 해제합니다.
2. '실행.command'를 더블 클릭합니다. 브라우저가 자동으로 열립니다.
3. 종료하려면 실행된 터미널에서 Ctrl+C를 누릅니다.

더블 클릭이 실행되지 않으면 터미널에서 압축을 푼 폴더로 이동한 뒤 실행하세요:
python3 server.py

Python 3가 필요합니다. npm 설치나 Cloudflare 로그인은 필요하지 않습니다.
HTML 파일을 직접 더블 클릭하지 말고 위 서버로 실행해주세요.

구성
- site/: Cloudflare 업로드 ZIP에 담긴 HTML, CSS, JS, 캐릭터, 공유 이미지
- server.py: 로컬 실행 서버
- 실행.command: Mac 실행 바로가기

로컬에서 달라지는 부분
- 통계 스크립트는 비활성화되어 운영 통계에 포함되지 않습니다.
- 결과의 '메인으로' 버튼은 로컬 메인으로 이동합니다.
- 도전장 링크와 앱 링크는 실제 운영 주소를 그대로 사용합니다.
- 외부 웹 폰트는 인터넷 연결이 필요하며, 연결되지 않으면 대체 폰트를 사용합니다.
- Instagram 및 휴대폰 공유창 동작은 실제 기기와 설치된 앱에 따라 다릅니다.
- 이 서버는 이 컴퓨터에서만 접근할 수 있습니다. 휴대폰에서는 운영 URL로 확인해주세요.
