## 첫 화면과 미리보기 흐름

피그마 원본 지도는 페이지 전체에 고정 배경으로 이어집니다. 첫 화면 왼쪽에 “히유 / 감정 공유 지도”와 짧은 소개를 표시하고, 오른쪽 원본 비눗방울과 감정들이 떠 있습니다.

첫 화면의 “버블을 눌러주세요!!” 안내에 따라 비눗방울을 누르면, 0.58초 동안 버블이 화면 중앙으로 확대되고 이어지는 0.82초 동안 감정 다섯 개가 펼쳐집니다. 펼쳐지기 전에는 페이지 스크롤을 잠그고, 완료되면 일반 스크롤로 휴대폰 미리보기까지 이어집니다. 아래로 이동했다가 맨 위로 돌아오면 첫 버블 화면을 복원하고 다시 클릭할 때까지 잠급니다. 상단 히유 로고로도 처음부터 다시 볼 수 있으며, 키보드 건너뛰기 링크는 직접 이동할 수 있습니다. 작은 버블은 원본 개별 SVG를 화면 안에 배치해 섹션 끝에서 잘리지 않으며, 하단 다운로드 영역은 구분선 없이 같은 지도 배경으로 이어집니다. 키보드 Enter·Space로도 시작할 수 있고, OS의 모션 줄이기 설정에서는 클릭 즉시 감정들을 펼칩니다.

## 네 가지 휴대폰 자동 시연

데스크톱(1000px 이상)에서는 네 휴대폰을 한 줄에 보여주고, 화면 폭에 맞춰 기기 크기와 간격을 조절합니다. 1000px 미만에서는 한 대씩 세로로 이어집니다. 좌우로 면을 돌리지 않고 화면 평면을 살짝 비스듬히 기울였습니다. 앱 전체를 3D 평면으로 합성하지 않도록 2D 회전만 사용합니다. 기기 외곽·상태 표시줄은 피그마 다운로드 원본이며, 기기 바깥에 사각 경계가 생기던 원본의 흐린 그림자 레이어만 제외했습니다. 앱 내부 감정 버튼은 원본 VectorDrawable을 사용합니다.

- **감정 등록**: 선택 → 메모 → 위치 선택 → 지도 등록을 4.3초마다 반복합니다. 앱 원본 `ic_emotion_*.svg`를 비율 그대로 사용하고, 기본 원형 그룹 스탬프로 등록합니다. 감정 등록·그룹 커스터마이징 시연의 스탬프 문구는 “히유”이며, 지도에는 4글자 이하 문구의 서로 다른 그룹 스탬프 여섯 개도 표시합니다.
- **프레스 연타**: 현재 앱의 Press 화면 배치에 맞춘 2+3 감정 버튼을 145ms 간격으로 쉬는 구간 없이 누릅니다. 카운트는 누적되고 기존 emotion-tap의 반동·입자 효과를 사용합니다. 기울어진 휴대폰에서도 버튼 중심에서 입자가 나옵니다.
- **랭킹**: 실제 앱의 바텀바처럼 스탬프 랭킹과 프레스 랭킹 화면이 1초마다 전환됩니다. 프레스 화면을 다시 보여줄 때마다 다음 필터로 이어져, 12초 동안 전체·다섯 감정 필터를 모두 보여줍니다. 두 랭킹은 같은 가상 그룹 10개를 사용하며, 그룹별 원본 스탬프 모양·색·문구는 탭과 필터가 바뀌어도 동일합니다. 교육기관·기수·실제 팀원 이름은 사용하지 않습니다. 내비게이션도 지도·프레스·그룹·랭킹 항목과 랭킹 내부의 스탬프·프레스 선택 상태를 따라 움직입니다.
- **스탬프 색**: 색상 시트를 유지하며 4.2초마다 색상 바를 부드럽게 왕복합니다. 슬라이더·HEX·스탬프 채색이 함께 연속적으로 바뀝니다. Design Spells의 Horizon 연속 그라디언트 모션을 참고했습니다.
- 휴대폰은 자동 시연 전용입니다. 전체 화면에 `inert`를 적용해 클릭·터치·키보드 포커스·드래그를 막고 수동 전환 버튼을 제거했습니다. 내부 앱 디자인과 자동 재생은 유지합니다.
- 화면 밖에 있는 휴대폰과 숨겨진 탭에서는 재생을 일시 정지합니다. OS의 모션 줄이기도 따릅니다.

시연은 로컬 상태와 문서화된 데모 fixture만 사용합니다. 새로고침하면 초기화되며 API 요청, 인증, 위치 조회, 서버 저장, 분석 추적을 하지 않습니다. 지도는 Figma에 포함된 원본 이미지이며, 실시간 지도 타일이나 실제 위치에 연결되지 않습니다. 음성 탭은 앱 원본의 마이크·타이머·파형 상태를 재현하는 로컬 시연이며, 실제 마이크 녹음이나 오디오 재생을 하지 않습니다. 초대코드와 랭킹 숫자는 예시 데이터이며 실제 데이터 기능으로 연결하지 않습니다.

## 화면 재현 범위와 검증

앱 원본의 벡터, 색, 문구, 현재 2+3 프레스 버튼 배치, 하단 내비게이션과 랭킹 상태, 그룹 목록 카드, 색상 시트, 지도 비눗방울 선택, 메모·위치 선택 순서를 웹으로 옮겼습니다. 네이티브 화면을 임베드한 것은 아닙니다. 실제 기기 스크린샷과의 픽셀 단위 일치는 아직 검증하지 않았습니다. 지도 배경·첫 화면 비눗방울·기존 감정 캐릭터·기기 외곽은 기존 Figma 원본을 유지합니다. 랭킹 화면에 필요한 내비게이션·왕관·전체 감정 이미지만 앱 원본 벡터에서 추가로 가져왔습니다. 감정 등록 휴대폰의 버블은 main의 `SoapBubble.kt` 좌표·색·그라데이션을 그대로 옮긴 `AppSoapBubble.jsx`를 사용합니다. 샘플 데이터는 데모용이며, 상태 표시줄은 Figma 온보딩 원본을 사용합니다.

자동화 테스트는 모션·랜덤·색상·스탬프 규칙, 네 시연의 장면·반복 경계, 랭킹 예시 화면 전환, 연속 색상 변화, 선택 색 유지, 기울어진 휴대폰 내부 입자 좌표를 검사합니다. 브라우저에서는 자동 색상·등록·연타·랭킹 재생, 휴대폰 클릭·키보드 입력 차단, 화면 폭에 따른 넘침을 확인합니다.
